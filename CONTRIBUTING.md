# Contributing

1. Pick an issue, create a branch `hslh-<id>-<slug>`.
2. Keep the change inside the issue's scope. Run `pnpm check` and, for UI changes, `pnpm e2e`.
3. Open a PR describing what changed, how you tested it, and what you did not test.

Decisions live in `docs/DECISIONS.md`. If your change needs a new decision, add a row there in the same PR.
