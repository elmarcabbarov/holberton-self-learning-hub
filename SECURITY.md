# Security

This app runs on your machine and reads your notes, so security bugs matter.
Report vulnerabilities privately to the maintainers (Holberton School Azerbaijan staff) instead of opening a public issue.

Current threat model and controls: [`docs/SECURITY_AND_TESTS.md`](docs/SECURITY_AND_TESTS.md).
Defaults: binds loopback only, read-only container filesystem, non-root user, no Linux capabilities.
