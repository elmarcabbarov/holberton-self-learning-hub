# Holberton Self-Learning Hub logo

Built on the Holberton School Azerbaijan lockup system (D-069), like Holberton Quiz:

- **Holberton**: the official Holberton wordmark vector, unchanged.
- **SELF-LEARNING HUB**: set like "AZERBAIJAN" in the official lockup (Host Grotesk 650, outlined). Long subtitles shrink to 92% of the wordmark width.
- Variants: `holberton-hub-stacked.svg`, `holberton-hub-inline.svg`. Colour via `currentColor`: red #E1003C, white or ink only.

Regenerate: `python build-logo.py <outdir> "SELF-LEARNING HUB" "Holberton Self-Learning Hub" holberton-hub` (needs fontTools + brotli and the holberton-az-slides kit). Brand assets are trademarks of Holberton School (see TRADEMARKS.md).
